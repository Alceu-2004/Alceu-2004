### 📅 Agendia · Agendamento online para pequenos negócios

Sistema para salões, barbearias e clínicas organizarem seus horários online. O cliente agenda sozinho, recebe confirmação e lembrete automáticos, e o dono acompanha tudo em um painel próprio.

- Confirmação automática e lembretes por **e-mail e WhatsApp**
- Cada negócio acessa **apenas os próprios dados** (arquitetura multi-tenant)
- **Bloqueio de conflito de horário**, coberto por testes automatizados
- **No ar em produção**, com link público

### 🏆 EventRank · Avaliação e ranking de eventos

Plataforma completa em que usuários avaliam eventos e acompanham um ranking, com login seguro e foco em organização e qualidade de código.

- Login e permissões com **autenticação JWT**
- API REST documentada, seguindo boas práticas
- Banco versionado com migrações e ambiente padronizado com **Docker**
- **Testes automatizados** no back-end
- Interface web em React

### 🎬 CineVault · App mobile para organizar filmes

Aplicativo Android para descobrir filmes, montar listas de "Assistidos" e "Quero assistir" e dar notas pessoais. Desenvolvido originalmente em equipe e depois evoluído por mim, com melhorias de estrutura, interface, integração com a API e distribuição do app.

- Busca de filmes em tempo real pela **API do TMDB**
- **Múltiplas contas** no mesmo aparelho, com dados separados
- Avaliação pessoal de 0 a 10
- **APK pronto para instalar**
